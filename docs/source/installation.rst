Installation
============

Flask-RPBAC is a small Flask extension designed to be added to your application with minimal
configuration.

Install with pip
----------------

Install Flask-RPBAC using pip:

.. code-block:: bash

   $ pip install flask_rpbac

Requirements
------------

Flask-RPBAC targets modern Flask applications and requires Flask 3.1 and newer. It is tested
with Python 3.12 and newer versions.
